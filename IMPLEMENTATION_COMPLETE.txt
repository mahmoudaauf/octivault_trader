🔍 HOW IT WORKS

Every 10 Seconds:
  1. Parse latest capital snapshot from logs
  2. Calculate returns, volatility, drawdown
  3. Check health of balance sync, positions, execution
  4. Detect issues based on thresholds
  5. Apply auto-fixes if problems found
  6. Export metrics to JSON

Every 30 Seconds:
  • Dashboard updates with live metrics

Auto-Fix Cooldown:
  • 5 minutes between same fix type
  • Prevents rapid oscillation
  • Allows system to stabilize


✨ AUTO-FIX EXAMPLES

Stale Balance Cache:
  Detected: Score drops below 60
  Fix: sync_authoritative_balance(force=True)
  Result: Fresh data fetched immediately

Position Misalignment:
  Detected: Wallet qty < position qty * 0.95
  Fix: Rebuild NAV from state
  Result: Positions recalibrated with current data
