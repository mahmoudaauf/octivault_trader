# Capital Allocator Implementation — Trades Now Sized

**Status**: ✅ COMPLETE
**Date**: 2026-05-06
**Commit**: fa0f5bc

## Problem

System was generating trading decisions (5-10 per cycle) but **all with 0.0 quantity**:
- ❌ Decision: `BUY BTCUSDT, qty=0.0`
- ❌ Decision: `SELL ETHUSDT, qty=0.0`

**Root cause**: No capital allocator in the native stack. Decision engine called `allocate_for_buy(symbol)` but the component didn't exist, so it fell back to `quantity = 0.0`.

## Solution

Created `NativeCapitalAllocator` (L6 governance layer) that:

1. **Allocates percentage of NAV per signal**
   - Default: 5% of portfolio NAV per buy signal
   - Configurable via `CAPITAL_ALLOCATION_PCT` environment variable
   - Formula: `quantity = (nav * allocation_pct / 100) / price`

2. **Reads from portfolio manager**
   - Gets current NAV via `portfolio_manager.get_nav()`
   - Gets symbol price via `portfolio_manager.get_price(symbol)`
   - Graceful degradation if portfolio manager unavailable

3. **Handles both buy and sell**
   - `allocate_for_buy(symbol)` → allocated quantity
   - `allocate_for_sell(symbol, position_qty)` → sell all (100% of position)

## Code Changes

### New File: `core_engine/native/capital_allocator.py` (112 lines)
```python
class NativeCapitalAllocator:
    async def allocate_for_buy(self, symbol: str) -> float:
        nav = await self._pm.get_nav()
        price = await self._pm.get_price(symbol)
        allocation_usdt = nav * (self._allocation_pct / 100.0)
        quantity = allocation_usdt / price
        return float(max(0.0, quantity))
```

### Modified: `core_engine/native/bootstrap.py`
- Added `capital_allocation_pct: float = 5.0` config field
- Added environment variable loading: `_float(e.get("CAPITAL_ALLOCATION_PCT"), 5.0)`
- Instantiate `NativeCapitalAllocator(portfolio_manager, allocation_pct)`
- Include in `NativeComponents` return

### Modified: `core_engine/native/app_context.py`
- Added `capital_allocator` field to `NativeComponents` dataclass
- Added to `NATIVE_CTX_KEYS` tuple for app context exposure
- Wire into `app_ctx["capital_allocator"]` in `build_native_app_ctx()`

### Modified: `core_engine/native/__init__.py`
- Export `NativeCapitalAllocator` in `__all__`
- Import from `.capital_allocator`

Set via environment variables:
```bash

```

Or override in code:
```python

    portfolio_manager=pm,
    allocation_pct=5.0,  # 5%, 10%, 2%, etc.
)
```
