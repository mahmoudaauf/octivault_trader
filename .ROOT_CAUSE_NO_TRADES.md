# Root Cause: Why System Generated 0 Trades Despite 10 Signals Per Cycle

## The Issue

```
5 trading cycles completed
├─ Signals generated per cycle: 10 ✅
├─ Decisions made: 0 ❌
├─ Executions: 0 ❌
└─ Result: No capital deployed, no trades
```

## Root Cause Chain

### Layer 1: Capital Allocator (NativeCapitalAllocator)
**File**: `core_engine/native/capital_allocator.py`
**Lines**: 72-89

```python
# Get current NAV
nav = await self._pm.get_nav()
if not nav or nav <= 0:
    logger.debug("NAV %s too low to allocate", nav)
    return 0.0  # ← RETURNS 0 if nav <= 0

# Calculate allocation
allocation_usdt = nav * (self._allocation_pct / 100.0)
quantity = allocation_usdt / price
return float(max(0.0, quantity))
```

**Issue**: If NAV ≤ 0, returns 0 quantity → no order placed

### Layer 2: SharedState NAV Not Updated
**File**: `core_engine/native/shared_state.py`
**Lines**: 91-97

```python
def __init__(self):
    # ...
    self.nav_usdt = 0.0  # ← Initialized to 0
    # ...

def update_nav(self, nav: float):
    self.nav_usdt = max(0.0, nav)

def get_nav(self) -> float:
    return self.nav_usdt  # ← Always returns 0 (never updated)
```

**Issue**: NAV stays at 0 because nothing calls `update_nav()`

### Layer 3: Orchestrator Doesn't Update SharedState NAV
**File**: `core_engine/native/orchestrator.py`
**Lines**: 256-266 (before fix)

```python
async def _phase_decide(self, signals: dict[str, Any]) -> list[Any]:
    # ...
    balance_usdt = self._balance_sync.get_balance().get("USDT", 0.0)
    # ↑ Has balance = $86.66

    decisions = self._decision_engine.decide(signals, portfolio, balance_usdt)
    # ↑ But NEVER updates SharedState with this value

    return decisions
```

**Issue**:
- `_balance_sync` has correct balance ($86.66 USDT)
- But `_shared_state.update_nav()` is never called
- So SharedState.nav stays 0
- Capital allocator sees nav=0, returns 0 quantity
- No trades placed

## The Feedback Loop (Broken)

```
┌──────────────────────────┐
│ BalanceSync (L1)         │
│ Correctly tracks: $86.66 │
└───────────┬──────────────┘
            │
            ▼
┌──────────────────────────┐
│ Orchestrator._phase_read │
│ Reads balance: $86.66    │
│ BUT: doesn't sync to     │
│      SharedState!        │ ← BUG HERE
└───────────┬──────────────┘
            │
            ▼
┌──────────────────────────┐
│ SharedState.nav_usdt = 0 │
│ (stays 0 forever)        │
└───────────┬──────────────┘
            │
            ▼
┌──────────────────────────┐
│ Capital Allocator        │
│ nav = 0 → quantity = 0   │
│ No orders placed! ❌     │
└──────────────────────────┘
```

## The Fix

**File**: `core_engine/native/orchestrator.py`
**Change**: Add NAV update in _phase_decide

```python
async def _phase_decide(self, signals: dict[str, Any]) -> list[Any]:
    """Phase 3: Generate trading decisions."""
    # ...
    balance_usdt = self._balance_sync.get_balance().get("USDT", 0.0)

    # ✅ ADD THIS: Update SharedState with current NAV
    if self._shared_state:
        self._shared_state.update_nav(balance_usdt)
    # ↑ This line closes the feedback loop!

    decisions = self._decision_engine.decide(signals, portfolio, balance_usdt)
    return decisions
```

## Why This Matters: The Bigger Picture

This is actually **the first step toward closed-loop feedback**:

1. ✅ **Now**: Balance syncs to SharedState NAV
2. ✅ **Result**: Orders can be placed
3. ✅ **Next**: Fills detected by FillTracker
4. ✅ **After**: P&L calculated from positions
5. ⏳ **Phase 2**: Feedback loop → adjust sizing

Once orders flow and fills are detected, we can implement the **Adaptive Capital Engine** (OPTION B from the feedback analysis) to close the true feedback loop.

## Lessons

1. **State synchronization is critical** — BalanceSync had the data, but it wasn't reaching the decision engine
2. **Background tasks need explicit wiring** — `_balance_sync` and `_shared_state` are separate components
3. **Missing update = silent failure** — No error thrown, just NAV stays 0 forever
4. **Single point of truth matters** — `SharedState.nav_usdt` is the source of truth for capital allocation

## Timeline

- **Before fix**: 0 trades/cycle (NAV = 0 blocks all allocations)
- **After fix**: Should see orders placed within constraints
- **Next**: Fill detection + P&L → enable adaptive sizing
