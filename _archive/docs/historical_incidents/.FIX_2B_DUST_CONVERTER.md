# FIX #2B: Binance Dust Converter Implementation

## Summary
**Status**: ✅ **DEPLOYED & VERIFIED**

Implemented automatic dust conversion using Binance's official `/sapi/v1/asset/dust` endpoint to clean up small balances and free portfolio slots.

## What It Does

### 1. **Exchange Client Enhancement** (`src/l1_exchange/exchange_client.py`)
Added new method: `async def convert_dust(assets: Optional[List[str]] = None) -> Dict[str, Any]`

**Converts small dust balances** (PEPE, LUNC, AVAX, XRP, DOGE, etc.) to BNB/USDT:
- Makes POST request to `/sapi/v1/asset/dust`
- Returns total USDT freed and per-asset conversion details
- Graceful error handling (non-blocking)

**Usage**:
```python
result = await exchange_client.convert_dust(assets=["PEPE", "LUNC", "AVAX"])
if result["ok"]:
    print(f"Freed: ${result['total_transferred']}")
```

### 2. **MetaController Integration** (`src/l8_lifecycle/meta_controller.py`)

**Added periodic dust conversion in evaluate_and_act()** loop:
- Runs every 30 cycles (~60 seconds at 2sec/cycle)
- Calls `exchange_client.convert_dust()` with configured assets
- Logs freed USDT and per-asset conversion results
- Emits `dust_conversion_complete` event to shared_state

**Configuration** (defaults):
- `FIX2B_DUST_CONVERT_INTERVAL_CYCLES=30` (check every 30 cycles)
- `FIX2B_DUST_ASSETS=["PEPE", "LUNC", "AVAX", "XRP", "DOGE"]`

**Helper Added**:
- `_cfg_list(name, default)` — parse config lists (converts strings/tuples to uppercase list)
