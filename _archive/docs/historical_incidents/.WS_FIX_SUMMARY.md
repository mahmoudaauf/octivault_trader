# WebSocket Issue Fix Summary

## Problem Identified
The WebSocket market data feed was hanging with the error:
```
[WS:Connect] No symbols to subscribe, waiting...
```

This caused a cascading failure:
1. WebSocket had no symbols to subscribe to
2. MarketDataFeed couldn't proceed with data collection
3. MetaController's main loop stalled
4. NO TRADE DECISIONS were ever made despite valid signals in cache

## Root Cause
The WebSocket's `_symbols_subscribed` set started **empty** and was never populated with symbols from SharedState's `accepted_symbols` dictionary. The architecture had these gaps:

1. **WebSocket startup** (`src/l1_exchange/ws_market_data.py`):
   - `start()` launches `_ws_main_loop()`
   - `_ws_main_loop()` calls `_build_stream_list()`
   - `_build_stream_list()` iterates over `self._symbols_subscribed` (which is empty)
   - Result: No streams are created, connection loop hangs

2. **Missing subscription mechanism**:
   - `subscribe()` method exists but is NEVER called
   - `accepted_symbols` are populated in MarketDataFeed but never passed to WebSocket
   - No fallback mechanism when symbols are unavailable

## Solutions Implemented

### 1. **Auto-Subscribe in WebSocket (ws_market_data.py)**
Added logic to `_ws_main_loop()` to automatically fetch and subscribe to symbols from SharedState:

```python
# Before attempting WebSocket connection, get symbols from accepted_symbols
if not self._symbols_subscribed:
    try:
        accepted = getattr(self.shared_state, "accepted_symbols", {})
        if accepted and isinstance(accepted, dict):
            syms = list(accepted.keys())
            if syms:
                await self.subscribe(syms)
                self._logger.info(f"[WS:AutoSubscribe] Subscribed to {len(syms)} symbols")
    except Exception as e:
        self._logger.debug(f"[WS:AutoSubscribe] Failed: {e}")
```

### 2. **Fallback Symbol Mechanism (ws_market_data.py)**
Added `_get_fallback_symbols()` method to provide bootstrap defaults if accepted_symbols is empty:

```python
async def _get_fallback_symbols(self) -> List[str]:
    """Get fallback symbols from bootstrap defaults if accepted_symbols is empty."""
    try:
        from src.l3_portfolio.bootstrap_symbols import DEFAULT_SYMBOLS
        if DEFAULT_SYMBOLS:
            symbols = list(DEFAULT_SYMBOLS.keys())
            self._logger.info(f"[WS:Fallback] Using {len(symbols)} bootstrap symbols")
            return symbols
    except Exception:
        pass

    # Hardcoded fallback: BTCUSDT, ETHUSDT, BNBUSDT, SOLUSDT, XRPUSDT
    return ["BTCUSDT", "ETHUSDT", "BNBUSDT", "SOLUSDT", "XRPUSDT"]
```

The WebSocket now uses this fallback if symbol subscription fails:
```python
if not self._symbols_subscribed:
    fallback_syms = await self._get_fallback_symbols()
    if fallback_syms:
        await self.subscribe(fallback_syms)
```

### 3. **Proactive WebSocket Subscription (market_data_feed.py)**
Enhanced the main run loop to subscribe the WebSocket to new symbols as they are discovered:

```python
new_symbols = sorted(current_symbols - self._known_symbols)
if new_symbols:
    self._logger.info(f"[MDF] accepted-symbol delta: {new_symbols}")
    await self._schedule_symbol_backfill(new_symbols)

    # === NEW: Subscribe WebSocket to new symbols ===
    if self.websocket_feed and hasattr(self.websocket_feed, 'subscribe'):
        try:
            await self.websocket_feed.subscribe(new_symbols)
            self._logger.info(f"[MDF] WebSocket subscribed to {len(new_symbols)} new symbols")
        except Exception as e:
            self._logger.debug(f"[MDF] WebSocket subscription failed: {e}")
```

## Expected Behavior After Fix

### Startup Flow
1. OrchestrationManager bootstraps `accepted_symbols` with DEFAULT_SYMBOLS (BTCUSDT, ETHUSDT, etc.)
2. MarketDataFeed starts
3. WebSocket starts via `_start_websocket()`
4. WebSocket's `_ws_main_loop()` attempts to get symbols from SharedState's `accepted_symbols`
5. WebSocket subscribes to those symbols
6. If symbols empty, uses fallback DEFAULT_SYMBOLS
7. WebSocket connects to Binance with proper stream list
8. MarketData flows into SharedState
9. MetaController builds decisions from cached signals
10. Trades execute normally

### Symbol Discovery During Runtime
1. New symbols appear in `accepted_symbols`
2. MarketDataFeed loop detects new symbols
3. Proactively calls `websocket_feed.subscribe(new_symbols)`
4. WebSocket immediately adds new streams
5. Real-time data flows for new symbols
