KEY ENDPOINTS:

API Server (localhost:8000):
  GET  /api/status           → Current system state
  GET  /api/ai-state         → Latest decision reasoning
  GET  /api/portfolio        → Positions + health metrics
  GET  /api/activity         → Event timeline
  GET  /api/health           → Component status
  POST /api/control/pause-buying       → Pause new BUY decisions
  POST /api/control/resume-buying      → Resume BUY
  POST /api/control/force-safe-mode    → Risk mitigation
  POST /api/control/cancel-open-orders → Cancel all pending
  POST /api/control/pause-all          → EMERGENCY: halt all trading
  POST /api/control/resume-trading     → Resume after pause

Dashboard (localhost:3000):
  SystemStateBar    → NAV, growth, free capital, mode, regime, health, throttle
  AIBrainPanel      → Why the AI decided (signals, gates, confidence)
  CapitalHealthPanel→ Capital allocation + risk warnings
  PortfolioCards    → Position grid with AI guidance
  ActivityTimeline  → Live event feed
  GovernancePanel   → Safe operator controls

SAFETY GUARANTEES:

✅ No Direct Exchange API Access from UI
   → All controls route through governance layer
   → UI cannot place orders or modify positions
   → UI can only request safe state changes

✅ Confirmation Modals for High-Risk Actions
   → PAUSE_ALL_TRADING requires explicit confirmation
   → CANCEL_OPEN_ORDERS requires confirmation
   → Prevents accidental emergency halts

✅ Read-Only Monitoring
   → 5 read-only endpoints provide full visibility
   → SharedState is the single source of truth
   → No mutations via HTTP except governance controls

✅ Type-Safe Data Contracts
   → TypeScript interfaces for all API responses
   → Frontend and backend guaranteed to match
   → Zero runtime surprises
