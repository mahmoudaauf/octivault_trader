PROBLEM IDENTIFIED
═══════════════════════════════════════════════════════════════════════════════

Aggressive REST polling (600/min vs 1200/min Binance limit) caused:
  • 418 "Way too much request weight used" IP ban every 2 minutes
  • System restart during ban → fresh ban triggered (cascading failures)
  • Impossible to trade: trapped in ban loop

═══════════════════════════════════════════════════════════════════════════════
SOLUTION IMPLEMENTED: THREE-LAYER PROTECTION
═══════════════════════════════════════════════════════════════════════════════

LAYER 1: bootstrap.py (Clear Expired Throttle States)
────────────────────────────────────────────────────

Location: core_engine/native/bootstrap.py, lines 434-441
Purpose:  Check if persisted throttle window has expired; clear if yes
Trigger:  Runs once at startup
Code:
  throttle_ts = float(getattr(shared_state, "exchange_throttle_until_ts", 0.0) or 0.0)
  if throttle_ts > 0 and throttle_ts <= time.time():
      logger.info("🟢 Throttle window expired; clearing throttle state")
      shared_state.set_exchange_throttle(False, reason="", until_ts=0.0)

Benefit:  Don't carry forward stale bans after system restart

────────────────────────────────────────────────────────────────────────────

LAYER 2: orchestrator.py (Skip Wallet Scans While Throttled)
────────────────────────────────────────────────────────────

Location: core_engine/native/orchestrator.py, lines 303-310
Purpose:  Gate expensive wallet scan operation on throttle state
Trigger:  Runs EVERY trading cycle (phase 0)
Code:
  if self._shared_state:
      throttle_ts = float(getattr(self._shared_state, "exchange_throttle_until_ts", 0.0) or 0.0)
      if throttle_ts > time.time():
          logger.debug("Exchange throttled; skipping symbol discovery this cycle")
          return

Benefit:  Prevent fresh 418 bans from wallet scans during active ban

────────────────────────────────────────────────────────────────────────────

LAYER 3: runtime_state_snapshot.json (Clear Disk State)
──────────────────────────────────────────────────────

Location: runtime_state_snapshot.json, lines 3-5
Purpose:  Start with clean throttle state
Changes:
  BEFORE: "exchange_throttled": true,          "exchange_throttle_until_ts": 1778164313.730
  AFTER:  "exchange_throttled": false,         "exchange_throttle_until_ts": 0.0

Benefit:  Clean slate for next bootstrap; don't restore stale ban
